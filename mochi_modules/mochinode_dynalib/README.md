# mochi_modules/mochinode_dynalib

Bridge from the embedded C99 libdynalib to JS (open/resolve/call symbols in any DLL)

- **Orientation**: native-first (engine plugin, loaded by the engine)
- **Status**: operational — implemented, integration/network dependent
- **Entry point**: `mbjs_init_module(ctx, name)`

## Layout

```
mochi_modules/mochinode_dynalib/
├── README.md

├── native/mochinode_dynalib.c
├── include/mochinode_dynalib_abi.h

```

## JS binding

`node_modules/mochinode_dynalib/index.js` membuka binari via 
`mochinode.loadNative('mochinode_dynalib.dll')`.

The flat file `mochi_modules/mochinode_dynalib.dll` is kept for loader/legacy 
compatibility; `lib/mochinode_dynalib_x86_64.dll` is the distribution copy with 
arch-suffixed naming.

Rebuild: see `native/` script in the root `mochi_modules/README.md`.
Generated by `script/gen_manifests.py`.
