# mochi_modules/mochisandbox

Realm-isolated sandbox runtime (create/run/runAsync/clone/free/count/setGlobal) with per-realm intrinsic isolation

- **Orientation**: native-first (engine plugin, loaded by the engine)
- **Status**: verified — exercised against mbjs.exe
- **Entry point**: `mbjs_init_module(ctx, name)`

## JS binding

`node_modules/mochisandbox/index.js` loads the binary via `mochinode.loadNative('mochisandbox.dll')`.

The flat file `mochi_modules/mochisandbox.dll` is kept for loader/legacy 
compatibility; `lib/mochisandbox_x86_64.dll` is the distribution copy with 
arch-suffixed naming.

Rebuild: see `native/` script in the root `mochi_modules/README.md`.
